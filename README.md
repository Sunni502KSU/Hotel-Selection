Hotel Selection Python coding project 

## Project Description
This Python program helps travelers find hotels based on:
- Destination city
- Amenities
- Customer rating
- Budget

## Features
- Hotel search by city
- Amenity filtering
- Rating filtering
- Budget filtering
- Hotel sorting by rating
- File handling using hotels.txt
- Error handling for invalid input
- Beginner-friendly interface

## Technologies Used
- Python
- File handling
- Functions
- Loops
- Lists
- Dictionaries

## How to Run the Program
1. Open the Python file
2. Run the program
3. Enter:
   - destination city
   - amenities
   - rating
   - budget
4. View matching hotels
